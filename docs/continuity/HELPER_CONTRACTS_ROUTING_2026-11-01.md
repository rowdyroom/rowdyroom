# Helper contracts, measured routing and background practice — 2026-11-01

Cloud managers retain authority, partner review and final decisions. Locals supply bounded advisory work; they cannot replace managers, expand permissions or turn coordinator observations into independently verified facts.

## Implemented

- Booking qualification extraction requires four named fields: source URL, publication date, current paid DJ vacancy and entertainment purchasing authority. Review helpers return one correction and missing external evidence. The helper receives a small relevant source packet instead of the full dependent-manager transcript.
- Deterministic checks flag missing or unexpected fields, copy mismatches, repetition and word-budget violations. Raw answers are retained; checks never fabricate missing values or grant semantic approval. Failed checks prevent an unchanged acceptance verdict.
- Production routing weighs recent quality and latency for the exact worker/model/task lane. Readiness, capability, lane restrictions, reservations and cooldowns still apply. Unknown performance receives bounded exploration rather than assumed speed.
- A helper has a20-second soft deadline; the manager's optional extra wait is capped at2seconds. Owner-supplied helper work overlaps the partner consultation. Late output is retained separately, without delaying the final manager answer.
- Every fifth automatic assignment per manager/lane is background practice; explicit production runs bypass that cadence. Practice submits without polling. A completed sample is offered to a later cloud manager for assessment and feedback. Timely production use and later practice acceptance are distinct.
- Metrics report acceptance without revision, timely acceptance, missing fields, repetition, median/tail latency, timeout history, added manager wait and practice attempts. Historical rows without new timing instrumentation are identified separately. No automatic weight training occurs.
