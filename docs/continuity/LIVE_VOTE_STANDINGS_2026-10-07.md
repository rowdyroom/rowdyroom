# Live vote standings — 2026-10-07

Status: deployed on the live cPanel show site; read-only live-page verification passed. A new real multi-singer ballot sequence is not yet owner-accepted.

The host queue page now has a persistent **Live Vote Standings** section below Rotation Queue, visible without opening More Tools. It uses the PHP `live_show` performance and vote records, not the older Supabase competition leaderboard. The `GET /api/vote/live-standings` endpoint ranks singers with votes from active or completed performances started in the prior 12 hours by exact vote average, then vote count, then performer ID. Multiple performances by one performer aggregate into one vote-weighted score. The first two entries are marked Top Two. The page refreshes this section with its existing two-second polling cycle and does not substitute old competition results if the endpoint fails.

The older **Competition Final Scores** section remains under More Tools and is labeled separate/legacy. The rotating current-leader banner now reads the PHP live standings. Queue order and end-performance behavior were not changed; the host still decides how to keep leading singers in rotation. The rolling 12-hour boundary is not a true per-show reset, so a recent prior-show or test ballot can appear until it ages out. On verification, the sole returned entry was a saved `Test Singer` score of 3.50/5 from two votes; no new vote was cast and no history was deleted.
